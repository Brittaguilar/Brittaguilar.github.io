# Instructions for Claude working in this repo

This is Britt Aguilar's GitHub Pages hub. Read README.md first; it defines the layout and the rules.

- Publish each artifact as `/<slug>/index.html`, self-contained, with the noindex meta tag.
- After every add or update, edit `artifacts.json`: set `updated` to today and keep the entry's other fields. Never rename a slug.
- Commit directly to `main`. Messages: `Add <slug>` or `Update <slug>: <what changed>`.
- Never publish anything marked internal, and never include budgets, credentials or contact details other than email addresses in a page. Email addresses are allowed in any artifact (a deliberate exception).
- Do not touch other artifacts' folders when updating one.
